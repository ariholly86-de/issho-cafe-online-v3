Catatan penting

Android: jika printer tidak muncul pada tombol Bluetooth di halaman ini, itu belum berarti printer rusak. Banyak printer kasir 58mm memakai Bluetooth Classic/SPP, sedangkan Web Bluetooth pada browser hanya dapat mengakses perangkat BLE/GATT. Untuk Bluetooth Classic Android, sistem Dapur nantinya perlu memakai aplikasi/bridge printer khusus atau mekanisme native agar data ESC/POS bisa dikirim.

Windows: jika Bluetooth printer membuat COM port, gunakan tombol COM di atas. Pilih COM printer dan halaman akan mencoba beberapa baud rate umum bila diperlukan.
