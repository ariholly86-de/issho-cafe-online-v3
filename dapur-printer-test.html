🖨️ Printer Dapur

ISSHO CAFE — tahap uji printer. Tidak mengubah order atau status pembayaran.
🟡 Belum ada printer terhubung

Hasil Uji

1. Hubungkan WP58D.
2. Tekan TEST PRINT.
3. Jika printer mencetak, beri tahu saya bahwa test berhasil.

Catatan: Bluetooth printer tidak selalu dapat dikendalikan langsung oleh browser. Jika Bluetooth tidak tersedia, kita lanjutkan dengan USB atau print bridge.

Contoh Struk

==============================
       ISSHO CAFE
       TEST PRINTER
==============================

Printer : WP58D
Status  : TEST

Tanggal : --/--/----
Jam     : --:--:-- WIB

==============================
       TEST BERHASIL
==============================
